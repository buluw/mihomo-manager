# v0.2.5

- **集合管理**：统一展示集合文件、来源及引用关系，支持新增、上传、引用、取消引用、改名和删除。
- **新增与设置**：Inline、File、HTTP 共用新增流程，文件支持批量拖拽上传；集合设置和声明可直接编辑，代理组支持选择及确认新建。
- **统一草稿**：正文、声明、引用和文件操作共用草稿，确认后统一保存或应用；管理列表与编辑器之间往返保留草稿和列表位置。
- **文件权限**：普通文件和内嵌集合按来源开放编辑，HTTP 缓存及订阅／配置提取内容保持只读。
- **列表体验**：可编辑集合优先排列，文件行采用统一高度摘要，展开后查看完整引用；桌面与移动端操作布局同步优化。
- **导航与反馈**：修复返回和前进的目标恢复，保留局部输入与版本冲突提示，统一确认／取消操作及集合分类间距。

本版提供 Linux x64 程序更新包，可通过“更新与维护”安装。PVE 新装继续使用 v0.2.4 模板，安装后可更新到 v0.2.5。
