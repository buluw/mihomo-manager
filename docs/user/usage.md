# 使用说明

## 配置与订阅

在“配置中心”上传或新建明确命名的 YAML，也可以添加 Clash/Mihomo YAML 订阅。订阅定时更新在服务端执行；更新源内容与应用到 Core 是两个步骤。

编辑器支持 YAML 格式化、换行和保存。保存允许保留尚未完成的草稿与诊断；“应用配置／切换配置”负责准备提取集合、生成独立运行文件、调用 Mihomo 完整校验和加载。只有加载成功后才更新成功记录。设置页的“保存并应用”使用同一运行文件流程。

源配置与运行配置可以分别查看。管理器设置中的明确覆盖值优先于源 YAML；“恢复配置值”撤销相应覆盖。源 YAML 的其他内容继续保留。

## 集合与节点整合

代理集合可以来自订阅、本地源配置提取、手动 File 文件或 HTTP Provider。提取设置支持节点过滤，并通过源 YAML 中的 `proxy-providers` 和代理组引用组合使用。规则集合通过 `rule-providers` 管理。

普通 File 文件可以编辑和同步改名；HTTP 缓存与自动提取内容由其来源维护。保存集合文件和刷新 Controller 运行态分别执行。删除或清理时按界面显示的文件来源、引用和身份确认目标。

代理页支持节点选择、延迟测试、集合健康检查和详情查看。显示合并可自动识别或手动调整成员，人工地区单独保存；这些设置只改变管理器的呈现，不改写 Mihomo 节点、节点名或分流规则。

## 规则、监控与设置

规则编辑针对明确源配置中的主 `rules`，支持顺序与策略调整。保存后再应用才能改变 Core 的运行规则。

总览、连接和日志页面显示运行数据；资源区域显示固定项目服务及受控目录的当前占用。系统信息提供只读网卡枚举；选择出口修改设置草稿，保存应用后才进入运行配置。

## 访问认证

在“访问认证”设置访问密码并开启认证。密码为 8–128 个字符，后台保存随机盐与 scrypt 哈希。会话有效期为 12 小时，刷新页面保留有效会话；sysinfo 重启后需要重新登录。

会话到期或撤销后业务请求停止，页面保留未保存草稿；重新登录恢复读取，写操作由用户重新确认。改密撤销已有会话，关闭认证需要验证当前密码。主动退出与改密遵循界面的未保存修改提示。

## Core 维护

“更新与维护”的 Core 卡片显示当前版本和检查更新入口。发现版本后可以查看官方发布说明，再下载或上传核心；候选通过版本与 SHA 校验后，明确确认安装。安装与本地回退会影响 Core 运行，应选择允许中断的时间。

下载、上传准备与安装是独立步骤。检查版本不会自动下载或安装；失败会保留实际错误状态。

## Web UI 更新与后台策略

Web UI 卡片显示服务端实际版本、官方发布说明、候选摘要、任务状态和本地上一版本。发布源固定为 buluw/mihomo-manager 的正式 Release；仓库或发布尚未公开、权限或额度限制、网络及解析失败分别显示。

下载／上传只准备候选。运行包通过包内清单、源码和构建身份、组件版本、Node 完整版本和 Linux 架构校验后，用户确认当前候选摘要再安装。自定义文件地址与 Core 地址分别填写；上传或自定义包需自行确认来源可信。安装任务独立于网页与 sysinfo，页面重连后继续查询。仅重启受影响的管理器服务，保留 Core 运行、认证和用户配置；失败时恢复切换前程序，成功后可回退至本地上一版本。更新涉及 sysinfo 时，已登录用户需重新登录；页面保留编辑草稿，完成编辑后再刷新页面资源。

“保存后台策略”持久保存自动检查、Web UI 自动下载、每日安装时间以及当前选择的固定来源和直连／当前 Mihomo 线路。周期为 1–168 小时；每日时间按界面标注的容器时区解释。关闭浏览器后继续运行。首次三项自动策略均关闭；自动下载需要自动检查，定时安装只接受已核对官方摘要且高于当前版本的候选。手动上传由用户确认安装。

外部代理地址及自定义文件 URL 仅用于当前页手动请求。保存策略时须明确选择支持的线路和来源；页面显示已保存线路、时区和下次任务时间。其他页面修改同一策略时保留当前草稿并提示重新读取。
